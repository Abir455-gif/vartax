HOW TO ADD THE REAL bKash / Nagad / Rocket / Upay / A-Challan / Sonali Seba LOGOS
==================================================================================

I can't generate or copy the official trademarked logo images myself (that would
be reproducing someone else's copyrighted/branded artwork). Instead, the site is
already wired up to display them automatically the moment you drop the correct
image files into this folder — no code changes needed after that.

Just save each official logo (PNG, transparent background preferred, roughly
120x120px, square) into this folder using EXACTLY these filenames:

    bkash.png          -> official bKash logo
    nagad.png           -> official Nagad logo
    rocket.png           -> official Rocket (DBBL) logo
    upay.png             -> official Upay logo
    achallan.png         -> official A-Challan / a-challan.gov.bd logo
    sonali-seba.png      -> official Sonali Bank / Sonali Seba logo

Where to get the official files:
    - bKash:      https://www.bkash.com (Media/Press or footer)
    - Nagad:      https://www.mynagad.com (Media/Press or footer)
    - Rocket:     https://www.dutchbanglabank.com (Rocket section)
    - Upay:       https://www.upaybd.com
    - A-Challan:  https://www.achallan.gov.bd
    - Sonali Seba: https://nbr.sblesheba.com or Sonali Bank's official site

Until you add these files, the site automatically shows a clean colored
letter-badge (bK / N / R / U / A / S) in the brand color instead — so nothing
looks broken in the meantime.

Once you upload the correct file with the correct name here and push to GitHub,
the real logo appears automatically on the payment cards.
